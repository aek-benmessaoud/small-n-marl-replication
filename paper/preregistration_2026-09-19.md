# Pre-Registration — Confirmatory Replication of the 8v8 Windowed Chao-U Result

Date: 2026-09-19
Status: **FROZEN** — no parameter below may be changed after the first training
run of the confirmatory batch. Changes would invalidate the confirmatory status
and degrade the study to exploratory.

Scope: this document pre-specifies the **confirmatory** phase (seeds 16-47,
never seen). The existing n=16 (seeds 0-15) is declared **exploratory** and is
excluded from every confirmatory test, including as secondary evidence.

---

## 1. Primary hypothesis

**H1 (directional):** the windowed Chao-U intrinsic reward, in the relaxed 8v8
regime (8 cameras, 8 targets, MAPPO, MATE), increases the sequential
oracle-localization metric `seq_loc` (paired, seed-matched) relative to the
`no_intrinsic` control.

- H0: no increase. Tested **one-sided** (right-tail) because the direction was
  fixed a priori by the exploratory phase and is the exact content of H1.
- The exploratory phase used two-sided Wilcoxon. The confirmatory phase uses
  one-sided α = 0.05. Rationale, to be stated in the paper: *the exploratory
  phase established the direction; the confirmatory phase tests that same
  direction*. One-sided is defensible only because this decision is
  pre-registered here, before the confirmatory runs.
- The two-sided p-value is still reported as secondary information.

## 2. Primary metric

- `seq_loc`: sequential oracle localization (see paper metrics section),
  evaluated on **5 deterministic episodes** per seed per arm, accumulation
  window **W=20**.

## 3. Sample size (FROZEN: N=32)

- Seeds: **16, 17, ..., 47** (contiguous integer seeds, no random draw, no
  rejection, no skipping), generated by the same protocol as the exploratory
  batch.
- **Power target:** one-sided α=0.05, Wilcoxon signed-rank, ARE≈0.955 vs
  paired t-test under near-normality (see section 11 for the power curve).

  | True effect d | Min N for 80% power | Power at N=32 |
  |---------------|---------------------|---------------|
  | 0.30 (MEI)    | 72                  | 0.51          |
  | 0.40          | 41                  | 0.71          |
  | 0.47 (observed) | 30                | **0.83**      |
  | 0.50          | 26                  | 0.87          |

- N=32 is chosen because it is the smallest power-of-2 batch that gives ≥80%
  power at the effect observed in the exploratory phase (d≈0.47) and supports
  transparent 8-seed wave splits. The MEI (d=0.30) is deliberately NOT the
  design target: it is a floor for "non-actionable", not the expected value.
  Power at the MEI is ≈50%, which is acknowledged and acceptable: a true effect
  at the MEI is a borderline finding either way.

## 4. Test and decision rule

Test: one-sided Wilcoxon signed-rank on the 32 paired per-seed differences,
α = 0.05.

Decision rule (pre-fixed, mutually exclusive outcomes):

1. **CONFIRMED** — p ≤ 0.05 AND observed d ≥ 0.30 (i.e. Δ ≥ +0.010 on
   `seq_loc`). → The positive framing stands; paper reports the confirmatory
   batch as the primary evidence for the 8v8 claim.
2. **SIGNIFICANT-BUT-NOT-ACTIONABLE** — p ≤ 0.05 but observed d < 0.30.
   → Statistically significant, practically negligible. Paper shifts to the
   regime-dependence / negative framing (Plan B, section 9); the positive
   result is reported as "small confirmed but non-actionable effect".
3. **NOT CONFIRMED** — p > 0.05 (in either direction). → Plan B. No seed
   addition, no re-weighting, no re-splitting to "rescue" the result.

No interim look, no sequential design, no `N` adjustment after the first
confirmatory training run.

## 5. Secondary analyses (disclosed but NOT decision variables)

- `C_end` (windowed): **two-sided**, exploratory within the confirmatory batch.
- `U_end`, `mean_seen`, `true_reward`, `simult_loc`, `loc_final`: reported,
  descriptive only.
- Wave decomposition in blocks of 8 seeds (16-23, 24-31, 32-39, 40-47),
  descriptive only, to expose heterogeneity — no exclusion of any block.

## 6. Minimal effect of interest (MEI)

- **d ≥ 0.30**, equivalent to Δ ≥ +0.010 on `seq_loc`.
- This is 57% of the exploratory effect (+0.0161, d=0.47). Below this value
  the effect is considered not practically actionable even if significant.

## 7. RND specificity test (extension to n=16)

Scope: extend the 8v8 RND intrinsic arm to the **same 16 paired seeds** as the
exploratory Chao-U 8v8 batch (controls `no_intrinsic` already exist for all 16).
Cost: 12 additional RND training arms (seeds 4-15) × 30,000 steps = 360k steps
(the 4 existing RND arms cover seeds 0-3).

Neutrality criterion (RND declared NEUTRAL iff **both** hold, evaluated on the
same 16 paired seeds as Chao-U):

1. The seed-bootstrap **95% CI** of Δ_RND includes zero for **both** `seq_loc`
   and `C_end`.
2. |Δ_RND| < 0.5 × |Δ_Chao| on `seq_loc` (paired, same seeds; Δ_Chao is the
   Chao-U effect measured on the same shared batch).

Grey-zone handling (pre-fixed):
- 0.5× to 0.8× of Δ_Chao: → contribution 3 **weakened** (paper states
  "magnitude comparable / inconclusive specificity").
- ≥ 0.8× of Δ_Chao: → contribution 3 **removed** from the paper.
- Also reported: the `U_end` inverted-signature comparison
  (RND roams vs Chao-U settles), as a secondary mechanistic argument, and the
  differing optimization dynamics (trained predictor network vs deterministic
  potential) are stated as a limitation of this control.

## 8. Heterogeneity diagnostics (gate before ANY confirmatory run)

Run and report before training seed 16:

- git hash / code version used for each training wave (0-3, 4-7, 8-11, 12-15).
- MATE, numpy, torch versions for each wave.
- Distribution of initial camera/target positions for seeds 12-15 vs 0-11
  (check for degenerate initializations).
- Reward distribution under a random policy per seed.
- Intra-episode variance per seed.
- `U_end` of the `no_intrinsic` controls per wave (a drift in the control is a
  strong infra-drift signal).

Outcomes:
- If an infrastructure/code/seed-init cause is found → fix, re-validate with a
  short smoke test, document, and THEN run the confirmatory batch on the fixed
  infrastructure. If the exploratory 0-15 batch is invalidated by the finding,
  stop and reassess the exploratory claims before touching seeds 16-47.
- If no cause is found → the heterogeneity is reported as a substantive finding
  (effect conditional on initial configuration, not mere noise), and the
  confirmatory batch proceeds as specified.
